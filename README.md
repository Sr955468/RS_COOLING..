# RS Durvasa Cooling Service

Initial clean Android project with:
- Offline service/customer records using Room
- Firebase Firestore sync
- PDF invoice generation
- Simple service entry screen
- Android Studio / Gradle project structure

Important:
Firebase needs your own `google-services.json`. The project will still contain all source/build files, but Firebase cannot be connected to your account until that file is added.

Open the folder in Android Studio and let Gradle sync.
